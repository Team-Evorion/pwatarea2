## 📖 Descripción

Este repositorio contiene los ejercicios desarrollados para la **Tarea Práctica 2** de la asignatura **Programación Web Avanzada**.

El proyecto tiene como finalidad fortalecer los conocimientos de **HTML5, CSS3 y JavaScript**, mediante el desarrollo de páginas web interactivas.

Además, se emplean **Git y GitHub** para fomentar el trabajo colaborativo, el control de versiones y la integración de los aportes de cada integrante.

## 🚀 Ejecución del proyecto

**Opción 1: Acceso en línea**

Ingresa al siguiente enlace:

https://team-evorion.github.io/pwatarea2/

**Opción 2: Ejecución local**

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Team-Evorion/pwatarea2.git
   ```

2. Abre la carpeta del proyecto en **Visual Studio Code**.
3. Ejecuta `index.html` en tu navegador o mediante **Live Server**.

---

## 📌 Metodología de trabajo

El proyecto se desarrolla de manera colaborativa mediante:

1. Creación de ramas para implementar cambios.
2. Desarrollo y prueba de los ejercicios.
3. Registro de modificaciones mediante commits.
4. Creación de **Pull Requests**.
5. Revisión e integración de los cambios en la rama `main`.
